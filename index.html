Pertanyaan Umum

OS apa yang bisa dipilih?

Linux: Debian, Ubuntu, dan Alpine. Butuh OS lain? Sampaikan saat order, kami cek ketersediaannya.

Apakah bisa upgrade paket?

Bisa. Naik paket kapan saja, selisih dibayar pro-rata. Turun paket berlaku di bulan berikutnya.

Bagaimana cara pembayarannya?

Transfer bank atau QRIS. Pembayaran dikonfirmasi manual, lalu VPS dibuat dalam 1x24 jam setelah pembayaran diterima.

Apakah data saya aman?

Setiap VPS terisolasi di atas virtualisasi Linux. Anda punya akses root penuh di VPS Anda sendiri. Kami tidak bisa melihat isi di dalamnya — dan tidak akan mencoba.

Kalau server saya mati?

Backup otomatis harian. Untuk data penting, tetap kami sarankan backup sendiri ke tempat lain — backup di server yang sama bukan backup.
